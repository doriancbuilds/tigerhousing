# Overview

TigerHousing is a full-stack housing search platform built for Towson University students to
pick through their housing options, both on-and-off campus, in one searchable interface

## Live Demo

https://tigerhousing.netlify.app/

## Features 
- Search filter and housing properties
- Natural-language search for room types, apartment sizes, amenities, and pricing periods
- Viewing property details, floor plans, pricing, amenities, and images

## Tech Stack
Frontend: React, JavaScript, Vite, Tailwind CSS
Backend: Node.js, Express, REST API
Database: PostgreSQL 

## Database
TigerHousing's PostgreSQL's database uses a normalized structure to organize:
- Properties
- Amenities
- Room Types
- Floor Plans
- Pricing
- Apartment Sizes
- Property Images
